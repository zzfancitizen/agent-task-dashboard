HOW IT WORKS

从一个任务，到一次交付。

GitHub 记录协作，本地 CLI 负责执行。看板不需要登录，也不保存你的密钥。

  1. 01

    连接任务仓库

    在已配置的仓库中启用 GitHub Actions 和 Pages。浏览此看板无需账户；发布和领取使用本地已有的 GitHub CLI 身份。

    gh auth login --hostname github.com
    taskboard --repo owner/repo init
  2. 02

    发布一项独立任务

    说明目标、允许修改的路径和验收条件，并固定源代码版本。在「发布任务」中导出 JSON，通过本地 CLI 创建 GitHub Issue。

    taskboard publish task.json
  3. 03

    领取，在本地执行

    先安装本地启动器，再点击「领取并运行」，或复制任务的 CLI 命令。CLI 等待 GitHub 确认归属后，创建独立工作目录并运行兼容的 Agent。

    taskboard install-launcher

    一键启动支持 macOS；其他平台请复制 CLI 命令。需已安装 Git、GitHub CLI，以及 Codex 或 Claude Code。

  4. 04

    检查结果，完成接力

    执行结果和验证记录回传到 GitHub。发布者检查交付后手动验收，源代码不会自动合并。

这是公开协作空间。任务说明与结果对访客可见，请仅发布适合公开的内容。

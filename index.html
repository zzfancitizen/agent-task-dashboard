HOW IT WORKS

从一个任务，到一次交付。

在熟悉的 Agent 会话中发起委托，让伙伴下载任务，在自己的电脑上接力。

  1. 01

    让现有 Agent 整理并发布

    打开「发布任务」，复制接入指引给正在使用的 Codex 或 Claude Code，也可下载发布接入包。Agent 整理完整上下文、资料与验收标准，先向你展示提案，只有你明确同意后才发布。

  2. 02

    领取任务，选择电脑系统

    在真实任务详情点击「领取任务」，选择 Windows、macOS 或 Linux 并下载运行包。完整解压后，双击包内的 Start-Taskboard 启动文件。

  3. 03

    跟随首次引导，选择 Agent

    首次使用会检查 Python、Git、GitHub CLI 和 Agent。缺少工具时提供官方安装指引，并引导登录。选择兼容 Agent 后，程序重新核验任务版本，等待 GitHub 确认领取，再开始执行。

    Windows 与 macOS 可能提示未知来源；Linux 文件管理器可能要求允许脚本作为程序运行。请按系统及组织要求核验来源。这是脚本包，未做原生应用签名。

  4. 04

    自动交付，由发布者验收

    执行结果和验证记录回传 GitHub，并通知发布者。原 Agent 会话可以继续检查结果；发布者验收后才计入完成榜，源代码不会自动合并。

发布与领取使用你的 GitHub 身份和仓库原有访问权限，无需加入应用成员名单。源代码仓库仍需可读权限。看板不保存登录密钥；任务与结果按仓库及 Pages 的访问设置可见。
